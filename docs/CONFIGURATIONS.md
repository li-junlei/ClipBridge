# 多配置与故障切换

添加配对或导入配置会新增一套连接，不替换其他配置。每套连接独立开关、删除、显示对方设备名和最后同步时间；最多保存 16 套。全局暂停停止发送和接收，关闭连接不会清除其凭据。

文本与图片发送给所有已开启的目标设备。文件发送时选择目标设备。同一设备通过加密设备信息交换的随机安装标识进行合并，不能只凭设备名确认；尚未确认身份的配置暂时作为独立目标。

同一设备的已开启连接组成备选路径。当前路径失效时尝试下一条，所有路径使用相同事件/传输标识，接收方持久化去重。网络响应丢失时可能重复上传密文，但不会因此重复写入剪贴板或重复弹出文件请求。换用其他目标设备的新配置不会收到之前排队的内容。

关闭某设备全部连接或全局暂停会放弃该目标的待发送文本，恢复后需重新复制；未过期附件可在恢复连接后继续。收到的剪贴板内容不会转发到其他配置，避免设备之间形成环路。

删除仅影响本机，不会撤销服务器令牌、删除对方配置或清除远端数据。重新安装导致安装标识改变时，不应继续把它当作原来的已确认设备。

“最后同步”是本机成功上传内容或成功接收写入内容的时间，不是心跳；空闲不刷新，发送成功也不保证对方已经保存。连接状态与最后同步时间应结合判断。
