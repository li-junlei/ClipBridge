# 路线图

## 已实现

- 双设备纯文本同步、认证与防重放、Java/.NET 加密互操作。
- Docker 中转、HTTPS 接入、扫码配对与手动导入。
- Windows 安装程序、托盘、开机自启动、配置删除。
- Android Miuix 界面、模块状态、隐藏桌面入口。
- 双方设备名与最后同步时间。
- HTTPS WebDAV 加密中转与本地扫码配置。
- 多配置独立开关、确认设备身份去重与连接故障切换。
- 图片分享、剪贴板图片、通知保存与接收方同意的多文件分块加密传输。

## 下一阶段

1. 扩展 Android 系统与 Hook 框架兼容性验证，验证休眠、网络切换、系统重启和后台恢复。
2. 发布签名、升级策略、设备撤销和密钥轮换。
3. 完善真实设备和不同 WebDAV 服务商下的附件传输验证。
4. 加密历史与本地索引、应用排除及更完整的故障诊断。

路线图不代表交付时间承诺。后续功能继续保持端到端加密，不引入明文兼容模式。
