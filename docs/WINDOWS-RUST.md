# Windows 原生客户端

## 结构

- `ui.rs`：GPUI 状态、同步组、统一弹层、配对二维码和设置。
- `runtime.rs`：事件驱动后台、状态保护、防回传、独立设备路径与任务调度。
- `crypto.rs`、`groups.rs`、`pake.rs`、`pairing.rs`：现有端到端协议与成员授权的 Rust 实现。
- `network.rs`、`transfers.rs`：复用 HTTPS 连接、限制响应、分块加密与流式附件。
- `platform.rs`、`instance.rs`：Windows 剪贴板事件、托盘、快捷键、DPAPI、系统通知和当前用户限定的单实例管道。

界面只在状态变化时接收刷新通知。网络任务并发运行，文件使用 256 KiB 块处理，界面线程不承担网络与文件加密。通道密钥按成员/连接变化缓存，附件清单只在变化或续期时写入。

## 安装与数据

运行 `installer/build.ps1` 生成安装程序。原生应用名与原安装位置保持一致，但本地配置独立保存到 `%LOCALAPPDATA%/ClipBridgeRust`。不读取旧 .NET 本地状态、不自动删除旧状态，也不启动旧客户端进程。

从旧客户端升级前先退出旧托盘程序。新版需要重新配对，Android 0.6.3 与现有支持同步组的中转仍兼容；服务器无需为 Windows 实现语言变化而升级。

## 安全

本地身份和同步状态用当前 Windows 用户的 DPAPI 加密并原子替换。未通过双侧安全码和身份密钥确认的设备不会获得组密钥。下载附件逐块认证、完整哈希校验，再保存到接收目录；文件不自动执行。服务器和 WebDAV 不接收内容明文或本机私钥。

性能必须区分打包体积、界面刷新、协议计算、网络与 GPU 占用；架构变化本身不等于所有指标都下降。实测范围记录在验证文档中。
