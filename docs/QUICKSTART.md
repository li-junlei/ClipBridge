# 使用指南

## WebDAV 连接

无需部署专用中转。Windows 添加配对时选择 WebDAV，填写已有目录的 HTTPS 地址、用户名和密码/应用密码。确认具有 GET、PUT、MKCOL 权限。连接成功后，手机扫码确认，再在电脑完成配对。

WebDAV 二维码直接包含凭据和密钥，不会自动过期；只供自己的手机扫描。WebDAV 目录仅保存密文文件。约两秒轮询，延迟与服务商限流、缓存和网络相关。当前只支持 Basic 认证。详情见 [WebDAV 指南](WEBDAV.md)。

## 专用中转连接

先按 [部署指南](DEPLOYMENT.md) 部署中转并配置 HTTPS，再安装 Release 中的 Windows 安装程序与 Android APK。

Android 在 LSPosed 或兼容框架中启用模块，仅勾选 `com.android.systemui`，按框架要求重启。应用本身不直接请求 root。

1. Windows 设备页点击“添加配对”，输入服务器的完整 HTTPS 地址（可含端口）以及服务器日志中的配对管理码。
2. 手机扫描二维码并确认服务器地址。已有配置时会询问是否替换。
3. 电脑显示邀请已领取后，点击“完成并启用”。此状态表示手机已领取加密信息，不是剪贴板写入回执。
4. 分别在两端复制无敏感信息的文本，验证对方实际粘贴结果。

二维码有效期五分钟，领取一次后失效，过期可刷新。配对管理码、二维码和手动配置文件均不要公开。仍可使用 `ClipBridge.Tool` 生成的配置手动导入，详见部署指南。

## 日常使用

- 状态页显示对方设备名和最后同步时间。设备名自动交换，通常约 15 秒内更新。
- 最后同步时间仅在本机成功发送到中转，或成功将远端内容写入剪贴板时更新。没有复制操作时它不会变化，不能单独用来判断进程是否卡死。
- Android 首页另显示模块状态、同步状态和已配置设备数；当前支持 0 或 1 台对端设备。
- Windows 关闭窗口后留在托盘，从托盘菜单“退出”才会退出进程。
- 两端可暂停同步；恢复后超过有效期的旧内容不会自动写入，请重新复制。

## 删除与更换配置

在设备页删除配置会停止本机同步，移除本机内容密钥和待发送消息。对方设备的配置和服务端认证不会被远程删除。仅保留加密的防重放计数，避免再次导入旧文件时回退状态。

电脑新建配对时，原连接保留至点击“完成并启用”。如果担心旧密钥或令牌泄漏，应在服务端清除对应配对认证并使用全新密钥重新配对；目前尚无图形化远程撤销流程。

## 客户端设置

**Windows**：设置中可启用开机自启动，启动后驻留托盘。安装版自带运行环境，升级前先退出旧版。升级和卸载默认保留用户配对数据，数据位于 `%LOCALAPPDATA%\ClipBridge`。

**Android**：设置中可隐藏桌面图标，开启前显示提示。隐藏后从 LSPosed / 兼容模块管理器的模块设置入口打开应用，再关闭开关可恢复图标。系统桌面缓存可能稍有延迟。更新模块后需要按框架要求重启设备。

## 连接排查

1. 检查 HTTPS 地址、端口、证书和 `/health` 响应。
2. 反向代理必须保留认证请求头，读取超时至少 40 秒。
3. 检查 Android 模块作用域、模块状态、两端暂停开关及设备时间。
4. 最近一次“已发送”表示中转接收成功，仍需在对端验证剪贴板写入。
5. 临时关闭其他剪贴板同步工具，排除跨产品回环。

反馈问题时只提供版本、系统/框架版本和脱敏的错误状态，不要附带管理码、二维码、配置文件或剪贴板内容。
