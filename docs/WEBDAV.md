# WebDAV 同步组

无需安装 ClipBridge 服务端。选择已存在的 HTTPS 目录，提供 Basic 账号和应用密码；服务需要允许 GET、PUT、MKCOL，清理附件时使用 DELETE。客户端不跟随重定向，不支持 OAuth、Digest、验证码或原版 SyncClipboard 文件格式。

## 创建及加入

任意设备打开“同步组 → 创建同步组 → WebDAV”，填写目录与账号。邀请设备时可扫码、粘贴完整邀请，或手动输入同一目录、账号和配对码。两端均核对六位安全码并确认。邀请包含存储凭据与短期配对口令，应当保密；不携带组内内容密钥。

0.6.1 已使用真实坚果云账号验证建组、配对码邀请、第三成员传播、双向密文文本、超过 1 MiB 的加密附件，以及 Android Java 发起的手机间配对。隔离测试组和邀请已清理，不代表所有账号或长期后台环境均已验证。

## 文件布局

新版组放在 `clipbridge/groups/<group-id>/`，邀请放在 `clipbridge/invites/<locator>/`，避免服务商对顶层目录名称的限制。已有早期组保留 `clipbridge-groups/<group-id>/` 布局；已有双设备组仍使用原目录，不搬移用户数据。

内容、成员清单、设备信息与附件清单均加密。每对设备使用独立密钥；附件先加密，再上传为一个 `.cbx` 对象，接收端拉取、验证并解密。只有接收方同意后才发送文件内容；图片使用通知预览及保存流程。

服务商可能忽略 `If-None-Match`。客户端对已观察到的握手槽进行一致性校验，检测冲突后中止，而不是依赖条件写入实现身份认证。邀请的五分钟有效期由客户端检查；过期不代表远端文件已删除。服务商回收站、历史版本及备份也不受客户端控制。

## 间隔与错误

WebDAV 采用轮询，不保证实时。可在设置调整文本、图片和文件检查间隔。坚果云有按账号计算的访问频率限制，较短间隔及更多设备会增加请求量；详见 [坚果云官方说明](https://help.jianguoyun.com/?tag=webdav)。被限频时应调大间隔并稍后重试，不需要更新 ClipBridge 专用中转。

界面分别提示账号或密码错误、目录权限、邀请不存在/过期及请求过于频繁。新设备加入过程中请保持邀请端页面开启。不要向公开 Issue 上传账号、应用密码、邀请链接或私有组状态。
