# WebDAV 中转

> 0.5.4：WebDAV 附件已恢复，使用单个加密对象与低频清单通知，两端均需升级。尚未验证具体网盘账号，不保证所有服务商均兼容。

适合已有 WebDAV 存储的用户，无需运行 ClipBridge Docker 服务。仍然只有客户端拥有内容密钥。

## 要求

- 有效 HTTPS 证书和一个已存在的目录，例如 `https://dav.example.com/folder/`。
- Basic 用户名与密码/应用密码，支持 GET、PUT、MKCOL；客户端自行创建子目录。
- 不需要 PROPFIND、MOVE、锁定或服务器端脚本，不跟随地址重定向；请直接填写最终地址。
- 当前没有 OAuth、Digest、验证码或原版 SyncClipboard 格式适配。非 ASCII 账号使用 UTF-8 Basic 编码，需要服务器支持。

推荐使用专用目录及权限受限的应用密码。服务商的请求限额和缓存行为可能影响同步。

## 配对

Windows 设备页添加配对，选择 WebDAV，输入连接信息并生成二维码；手机扫码、核对地址并确认，最后电脑点击完成。电脑在明确完成前保留原连接。

二维码内容是本地生成的完整 Android 配置，包含 WebDAV 凭据和内容密钥，不经过远程二维码服务、不上传存储。它不是一次性邀请，不会自动过期，只供自己的设备扫描。请勿分享截图。连接信息太长时，需要缩短目录地址或应用密码。

## 文件与同步

```text
<所填目录>/clipbridge/<pair-id>/
  <设备A-id>.clip.json
  <设备B-id>.clip.json
  <设备A-id>.device.json
  <设备B-id>.device.json
```

每个客户端只写自己的文件，读取对方文件；双方设备文件互不覆盖。所有内容为加密 Envelope，不上传明文配置、明文内容或内容密钥。设备名使用独立派生密钥。

文本约每 30 秒检查新文件，空目录或对方尚未上传视为正常等待。GET 禁用缓存；服务器若强制缓存，可能增加延迟。PUT 使用固定内容长度。网络异常按退避策略重试。内容仍受十分钟有效期与客户端防重放检查约束。

服务器可能保存旧版本和备份。附件完成后会尝试删除密文块；剪贴板和设备信息文件持续保留；删除本机配对也不会删除 WebDAV 数据。确认两端均不再使用某组配对后，可以在 WebDAV 中人工删除对应目录。

## 验证范围

使用隔离测试服务检查 .NET 和 Android Java HTTP 实现的目录创建、双向密文、认证、缺失文件、禁止重定向和响应大小限制；同时检查密文不含明文内容、密钥与密码。尚未针对具体第三方 WebDAV 服务商进行账号实测，不承诺所有实现均兼容。

```sh
python tests/webdav_flow.py
```

.NET 检查不依赖真实账号。Android JVM HTTP 检查使用 Gradle 已下载的 OkHttp/Okio/Kotlin 依赖，需要先构建 Android，并配置 JDK；缺少这些依赖时该部分会明确跳过。

## 附件扩展（0.5.4）

每个方向使用 `<device-id>.transfers.json` 加密清单通知，文件数据保存为 `attachments/<sender-id>/<transfer-id>.cbx`。清单携带文件名、大小、摘要、同意/拒绝和上传完成状态，全部在设备端加密。WebDAV 无法主动推送，接收端约每分钟读取清单；传输可能需要数分钟。

图片先加密上传，上传成功才发布 ready 清单。普通文件先发布请求，只有接收方同意后才上传文件内容，成功后更新 ready。接收端下载、逐块解密并验证完整 SHA-256，才写入剪贴板或目标目录。

一个附件只使用一次 PUT 上传和一次 GET 下载数据，避免 100 MiB 文件拆成 400 次远端请求。对象内部仍按 256 KiB AES-GCM 分块，布局为各块 `nonce(12) + ciphertext + tag(16)` 顺序拼接，无额外明文头；加密清单中的 size/chunks 决定每块边界。上限 100 MiB，不整文件载入内存。上传失败会重传整个对象，暂不支持大文件断点续传。

文本约 30 秒检查、附件清单约 60 秒检查、设备信息约 5 分钟交换；空闲清单约 15 分钟续期。连接或权限失败退避约 5 分钟，状态变化才立即写入通知清单。服务商若另有限频或配额，仍可能延迟。

建议允许 DELETE。对端确认完成或拒绝后发送方尝试删除密文对象；不支持 DELETE 时保留密文，需自行清理服务端目录/回收站。请求有效期一小时，旧版待发送任务建议取消后重发。两端至少使用 0.5.4，旧版分块对象格式不兼容。

## 0.5.4 可调间隔

当前默认文本 2 秒、附件 3 秒；两端设置均允许 1～300 秒，覆盖上文 0.5.3 的固定间隔。专用中转文本仍为长轮询。间隔只控制当前设备，服务商限频仍需自行调整。
