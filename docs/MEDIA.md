# 图片与文件

> 0.5.4：WebDAV 附件已恢复，使用单个加密对象与低频清单通知，两端均需升级。尚未验证具体网盘账号，不保证所有服务商均兼容。

## 发送与接收

| 操作 | 行为 |
| --- | --- |
| Android 分享图片到 ClipBridge | 默认转换为 PNG，发送给所有已开启目标，进入 Windows 剪贴板 |
| Windows 复制图片内容 | 自动同步到 Android，通知预览并提供 ✅ 保存 / ❌ 丢弃 |
| Android 分享普通文件 | 可多选，选择一个目标设备，等待接收方同意 |
| Windows 托盘“发送文件” | 可多选，选择目标设备，每个文件独立等待接收方同意 |
| Windows 资源管理器右键发送 | 在设置中启用；Windows 11 可能需要“显示更多选项” |

Windows 接收普通文件默认保存到用户 `Downloads/ClipBridge`，可在设置更改。Android 普通文件保存到 `Download/ClipBridge`；图片确认后保存到 `Pictures/ClipBridge`。同名不同内容不会覆盖已有文件。

仅接收方需要同意。请求包含加密的文件名、类型、大小与摘要；文件数据在同意前保留于发送设备。拒绝或请求过期后不上传文件内容。图片允许自动传输到接收方缓存，但手机必须确认才会保存到相册。

每个文件最多 **100 MiB（104,857,600 字节）**，一次最多选择 20 个文件，单机附件缓存限制 512 MiB。更大的文件请使用网盘、局域网传输等方案。静态图片默认转换为 PNG，最多 2000 万像素；需保留原始格式、动画或发送更大图片时，在 Android 分享界面选择按文件发送。

## 连接与通知

两端更新至 0.5.0。专用中转必须同步升级，旧中转仍可同步文本，但不提供附件接口。反向代理保留 Authorization，并允许至少 263 KB 请求体及 45 秒请求超时。WebDAV 使用原有 HTTPS/Basic 连接，建议允许 DELETE 以清理已完成的密文块。

Android 需要允许通知，附件服务运行时有常驻通知。OEM 后台限制可能影响到达时间；首次安装请打开客户端授予通知权限。LSPosed 作用域仍只需要 SystemUI，附件分享和接收运行于客户端自身，不直接调用 root。

文件请求有效期一小时。传输逐块进行，256 KiB 一块，AES-256-GCM 加密并在接收后校验 SHA-256；不会一次性将 100 MiB 文件读入内存。加密开销通常小于网络和 WebDAV 请求开销，实际速度取决于设备、带宽和服务商延迟。

完成或拒绝后，发送方尝试删除远端密文块。旧版专用附件接口对超过 24 小时的对象停止提供读取，并在后续写入时清理；新版组存储不承诺按时间自动清理，WebDAV 的历史版本、回收站和备份由服务商管理。删除本机同步组不等于删除远端目录。

## 当前验证边界

已检查分块加密互操作、请求先于内容、拒绝不上传、故障切换、去重和 Android 模拟器分享/通知/相册流程。已使用真实坚果云账号验证加密附件往返；实际 HyperOS / Vector 和跨设备长时间后台传输仍需验证。具体兼容性以目标设备验证为准。

## Windows 手动上传剪贴板

设置中的“复制图片自动发送”默认开启，关闭后不再自动发送新复制的图片；文本自动同步不受此开关影响。点击“手动上传当前剪贴板”输入框，输入 Ctrl/Alt/Shift 与按键组合设置全局快捷键，Backspace/Delete 清除。快捷键可主动上传当前文本或图片，包括关闭自动图片同步时，以及再次发送同一张图片。快捷键被占用时不会保存冲突的组合。全局暂停仍会阻止手动上传。

## 0.5.4 通知操作

Android 设置可进入“附件接收常驻提示”系统通知分类开关，只隐藏空闲提示，保留文件与图片通知。接收完成通知可打开保存后的内容 URI。Windows 完成通知提供打开文件与所在位置按钮，本地协议仅接受接收记录及本机生成的通知令牌，不接受任意路径。Windows 通知最长保留约 24 小时。
